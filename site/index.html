ObSink

ObSink keeps an Obsidian vault the same on every device you use, through a server that only ever stores encrypted files. The key is derived from a passphrase you choose and never leaves your devices; the server sees file sizes and timing, not notes, paths or names. Conflicts are shown, not merged: you pick a side or keep both.

Accounts are invite-only. Ask someone who already uses this server for an invite code and enter it the first time you sign in.

macOS

A menu-bar app that watches the vault folder and syncs as you edit.

Download for macOS Apple Silicon and Intel, one download.

Command line

The same sync as a tool for scripts, servers and terminals.

curl -fsSL https://obsink.spencerjireh.com/install.sh | sh

The script downloads the latest release, checks its SHA-256 and installs obsink into /usr/local/bin. Or take the tarball yourself.

Browser

No install: open ObSink in the browser, sign in and pick the vault folder. It syncs while the tab is open. Chrome and Edge only, since the folder is read through the File System Access API.

iOS

The iOS app puts the vault in the Files app for Obsidian to open. It is on TestFlight; ask for an invite to the test group.

Source and self-hosting

Everything is on GitHub under the MIT license, including the server. Running your own is a docker compose up behind a TLS proxy; see docs/self-hosting.md.

The API this site talks to is obsink-api.spencerjireh.com.
